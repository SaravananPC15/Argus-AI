# Argus Example Commands

These are example phrases you can use with Argus once the project is set up.

## General Chat

- "Hi Argus, what can you do?"
- "Give me a summary of the project architecture."
- "What should I work on next in this repo?"
- "Explain this bug in plain English."
- "Rewrite this into a cleaner version."

## Research & Planning

- "Research the best local AI stack for a privacy-first assistant."
- "Compare Docker vs. local process isolation for script execution."
- "Summarize my notes on this project."
- "Find the best approach for adding secure workspace automation."
- "Create a 3-step plan for shipping this project as an open-source tool."

## File & Workspace Actions

- "Read the README and summarize the setup steps."
- "Open the project folder and tell me what is missing."
- "List the main files and what each one does."
- "Create a quick architecture diagram in markdown."
- "Find all files related to the launcher and remote control."

## Git & Development

- "Check the git status and tell me what changed."
- "Create a commit message for these changes."
- "Push the current branch to GitHub."
- "Review my recent commits and explain the project evolution."
- "Show me the most important changes in this repo."

## Remote / Phone Access

- "Open the dashboard on my phone."
- "Start the remote launcher from my device."
- "Mirror my screen on the phone."
- "Move the cursor to the center of the screen."
- "Open the macro deck and run the remote setup command."

## Calendar & Personal Tasks

- "What is on my calendar tomorrow?"
- "Add a dentist appointment for Friday at 3 PM."
- "Summarize my schedule this week."
- "Remind me of my key deadlines."

## Vision & Room Awareness

- "Turn on the camera feed."
- "Describe what is in the room."
- "Start vision detection and show the objects detected."
- "Use the gesture control system for navigation."

## Voice Control

- "Start listening for my commands."
- "Wake the assistant."
- "Use the voice confirmation flow for this risky action."
- "Tell me which features are enabled right now."

## Search & Knowledge

- "Search my local documents for a note about onboarding."
- "Use the document library to find the relevant file."
- "Find any notes about security or remote access."
- "Summarize the most relevant local sources around this topic."

## Multi-Agent / Debate Flow

- "Convene the round table on this workflow issue."
- "Have the team review my architecture and suggest improvements."
- "Get the council to compare these two approaches."
- "Ask the specialists to debug this issue with a security lens."

## Security & Safety

- "Confirm the risky git push before executing it."
- "Run the script but ask me before doing anything dangerous."
- "Check the security posture of this project."
- "Review the recent audit log."
- "Tell me whether any risky actions were attempted."

## Advanced / Experimental

- "Use the frontier model to think through this deeper reasoning problem."
- "Run the database indexing optimizer and tell me what it would change."
- "Analyze this function and estimate its runtime complexity."
- "Translate this schema into a document-oriented data model."
- "Create a mind map of this project and its core components."

## Example Launch Commands

```bash
python launch.py
python launch.py --mode wake
python launch.py --mode legacy
python launch.py --minimal
python launch.py --list
```

## Tip

Argus works best when you give it clear action-oriented prompts rather than vague requests. For example:

- Better: "Open the dashboard and summarize the latest audit log."
- Weaker: "Check stuff for me."

The more specific the task, the more precise the routing and execution.
